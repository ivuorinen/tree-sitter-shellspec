# spurious-breaking: `BREAKING CHANGE:` footer on the initial implementation commit

## Problem

spurious-breaking. The first feature commit carries `BREAKING CHANGE: Initial implementation of tree-sitter-shellspec grammar` (body line 18) although there was no prior surface to break.

## Evidence

`git show -s --format=%B 7353f27` line 18. Pushed; no release automation; no version consequence.

## Impact

None today; a commit-driven release tool would compute a major bump for the initial release.

## Fix

No action on pushed history; if release-please is adopted, set its initial version explicitly (`Release-As: 0.1.0`).
